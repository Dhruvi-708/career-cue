# CareerCue Multi-Page Deliverable Files

As requested, each page of the CareerCue platform is separated into distinct HTML, CSS, and JavaScript files, linked with the shared CareerCue logo and design system:

### 1. Home / Landing Page
- `home.html` - Semantic landing page with hero, statistics, cue match signals, and connected modules.
- `home.css` - Custom layout styles for hero, visual cue card, and feature grid.
- `home.js` - Dynamic counter and live cue indicator logic.

### 2. Career Assessment Page
- `assessment.html` - 4-step diagnostic skill and trajectory questionnaire.
- `assessment.css` - Multi-step progress bar, option cards, and result breakdown styling.
- `assessment.js` - Step navigation, fit scoring algorithm, and dynamic track recommendation.

### 3. Jobs & Internships Page
- `jobs.html` - Curated tech jobs board with search, filters, and modal overlay.
- `jobs.css` - Responsive job card items, match percentage badges, and modal dialogs.
- `jobs.js` - Real-time filtering by role category, keyword, and match score, with 1-click application handler.

### 4. AI Resume Doctor & Builder
- `resume.html` - Dual-pane interactive editor and printable resume sheet.
- `resume.css` - Live ATS dial meter, print styling, and formatted sheet design.
- `resume.js` - Real-time preview synchronization and AI cue bullet enhancement logic.

### 5. AI Mock Interview Studio
- `interview.html` - Role-based practice sandbox (Frontend, Backend, Fullstack, Product).
- `interview.css` - Question card, pulse recording indicator, and score matrix.
- `interview.js` - Simulated speech transcription, AI evaluation analysis, and role switching.

### 6. 1-on-1 Mentorship Network
- `mentors.html` - Senior engineering and leadership mentors from Google, Microsoft, Stripe, and Uber.
- `mentors.css` - Verified mentor cards, specialty badges, and booking interface.
- `mentors.js` - Interactive session booking modal with calendar confirmation.

### 7. Application Pipeline Tracker
- `dashboard.html` - Visual Kanban board for job applications (Applied, Screening, Technical, Offer).
- `dashboard.css` - Kanban column layouts, statistics cards, and stage badges.
- `dashboard.js` - Dynamic application management, stage progression, and new application intake.

### Shared Assets
- `common.css` - Global design system tokens, typography (Plus Jakarta Sans & Outfit), navigation bar, buttons, and footer.
- `logo.svg` - Official vector CareerCue logo with electric indigo and emerald gradient compass cue.
